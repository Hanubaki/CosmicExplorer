Cosmic Explorer is a space-themed WordPress block theme, designed for science and space exploration projects. Turkish student project. (Uzay kaşifi teması).

== Description ==

Uzay temalı, gezegenler ve evren hakkında bilgi vermek için tasarlanmış bir WordPress blok teması. Interactivity API ve Theme.json v3 kullanılarak modern web standartlarına uygun şekilde geliştirilmiştir. 

Features:
- Full Site Editing (FSE) support
- Block patterns
- Interactivity API for dynamic features
- Multiple style variations (Deep Space, Nebula Glow, Retro Sci-Fi)

== Installation ==

1. Upload the `cosmic-explorer` folder to the `/wp-content/themes/` directory.
2. Activate the theme through the "Themes" menu in WordPress.
